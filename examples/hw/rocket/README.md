# rocket — a rocket-chip core running from DRAM

A 64-bit RISC-V core runs a program that the host loads into the board's DRAM,
and writes its results to a small FPGA memory the host reads back. It is the
`dram` example with a real CPU as the DUT.

- `src/HNSCore.v` — the core, generated by Chisel. One RV64IMAC Rocket core
  (no VM, FPU or BTB), a 4KB ICache, a 4KB DTIM instead of a DCache, no
  interrupts, and a debug module on DMI.
- `src/hns_core.veryl` — a Veryl wrapper that instantiates it as
  `$sv::HNSCore`. `include(inline, "HNSCore.v")` puts the Verilog into the
  wrapper's output, so it reaches synthesis.
- `sw/` — a smoke test that writes `HNS!`, `misa`, `mhartid` and a counter to
  MMIO. `smoke.elf` is prebuilt; `make -C sw` rebuilds it with a RISC-V GCC.
- `bringup.hio` — hold the core in reset, load `sw/smoke.elf`, release it, and
  read what it wrote.

The core maps DRAM at `0x8000_0000` and MMIO at `0x0002_0000`.

```bash
veryl harness gen --target digilent/arty-a7-35
make -C hns/syn
hio program
hio run bringup.hio
```

## Where the core comes from

`src/HNSCore.v` is generated, unmodified, by
[rocket-src](https://github.com/shuntarot/rocket-src) from
[rocket-chip](https://github.com/chipsalliance/rocket-chip) v1.6
(`44b0b8249`). The configuration is `HNSRocketConfig` in rocket-src's
`src/main/scala/System.scala`; `make` there writes `outputs/HNSCore.v`.
